OBSERVACOES
==========

- Os modelos diretos da xAI e da DeepSeek aparecem conforme a chave API
  correspondente esteja preenchida e seja considerada plausivel pelo app.
- O IA-Proxy nao usa chave API no cliente e fixa o reasoning minimo conforme
  o modelo encaminhado.
- O codigo ativo atualmente nao define avare:8500 como fallback do IA-Proxy.
- O nome grok-4.20-non-reasoning aparece apenas como alias legado de
  compatibilidade; a opcao atual e grok-4.20-0309-non-reasoning.
