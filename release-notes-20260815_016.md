# SIG Windows 20260815_016

Pacote completo para instalação nova ou reparo.

- Texto do botão de atualização simplificado: "Atualizar" quando disponível e
  progresso "n/total" durante o download dos arquivos alterados.
- Atualização incremental (arquivo por arquivo, com rollback protegido) no
  botão do SIG e no SigUpdater.exe; pacote ZIP e full no GitHub como
  contingência.

> Instalação: extraia o ZIP e execute `sig.exe` (mantenha `_internal` ao lado).
> Atualização: botão "Atualizar" no SIG, ou `SigUpdater.exe`.
