# Ponteiro de handoff do SIG Windows

Este arquivo nao duplica instrucoes operacionais.

- Regras universais: leia `AGENTS.md`.
- Roteamento: leia `docs/agents/README.md`.
- Build, release, sincronizacao, instalador ou updater: leia `UPDATE.md` antes
  de executar qualquer comando.
- Diagnostico de migracao antiga: leia
  `docs/maintenance/release-history.md` somente se necessario.

Use os numeros, caminhos, comandos, criterios e resultados reais encontrados nas
fontes canonicas. Nao copie versoes, contagens de PASS, credenciais ou estado
operacional para este ponteiro.
